## Guia Algoritmos y Programacion 1

Bienvenido! Este repositorio esta creado unica y exclusivamente con el fin de demostrar los proyectos realizados en la materia de algoritmos y programacion 1 (AyP1) En la universidad nacional tres de febrero (UNTREF)

## Proyecto Final

Este es un proyecto creado exclusivamente para correr en Green Foot, es un mini juego en el cual se debe derrotar a un Boss siguiendo ciertos pasos y condiciones, dentro del mismo juego se encuentra una demostracion del mismo el cual ejecuta los pasos correctos para derrotarlo.

Este fue el TP y proyecto final de la materia.
